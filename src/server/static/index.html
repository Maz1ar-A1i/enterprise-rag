System Architecture: Experimental Variants vs. Production Runtime Pipeline

Architectural Separation
7 Experimental Configurations / Ablation Variants:
  1. L1 Base LLM: Standalone model without grounding.
  2. L2 Naive RAG: Untuned dense retrieval + prompt assembly.
  3. L3 Fine-Tuned LLM: Domain-adapted generator without retrieval.
  4. L4 Advanced RAG: Typo correction, query decomposition, hybrid retrieval.
  5. L5 FT LLM + Advanced RAG: Hybrid retrieval + FT generator.
  6. L6 Trained Retriever/Reranker + Generator: Fine-tuned BGE + QLoRA reranker.
  7. L7 Final Defended System: Security envelope quarantine + conflict resolver + NLI verifier.
8-Stage Production Runtime Request Flow:
Query → Query Processing → Retriever (Hybrid) → Reranker (FT) → Security Quarantine → Version Conflict Resolver → Generator → NLI Claim Verifier → Answer / Refusal

Every incoming request passes through this linear, defended 8-stage sequence to guarantee zero hallucination.
